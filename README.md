# أثر
### ما تتركه الحياة فينا

أثر مساحة إنسانية وفكرية تحاول فهم الإنسان من الداخل؛  
العلاقات، الطفولة، الفقد، الألم، المعنى، والرحلة النفسية التي تصنعنا.

لسنا هنا لإعطاء إجابات جاهزة،  
بل لمحاولة رؤية أنفسنا والحياة بعمق أكبر.
ما تتركه الحياة فينا، وما نصنعه نحن من هذا الأثر.
